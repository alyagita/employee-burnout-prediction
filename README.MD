# Predicting Employee Burnout Using Ensemble Machine Learning

## Overview
This project focuses on analyzing employee burnout and building predictive models using ensemble machine learning techniques, specifically boosting and stacking, to estimate employee Burn Rate and identify key contributing factors. The model is developed to support early detection of burnout and provide data-driven insights for workplace well-being strategies.

---

## Key Contributions
- Analyzed employee burnout patterns using exploratory data analysis and statistical methods  
- Built predictive models using ensemble learning techniques (Boosting and Stacking)  
- Identified key factors influencing burnout, such as Mental Fatigue Score, Resource Allocation, and Tenure  
- Evaluated model performance using MSE and R² metrics to ensure predictive reliability  

---

## Outcome
- Developed a machine learning model capable of predicting employee burnout levels  
- Provided insights into the most influential factors affecting burnout in employees  
- Demonstrated that ensemble methods (especially boosting and stacking) improve prediction performance
